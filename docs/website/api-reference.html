DB

Core database handle managing master + replica connections. Created via Open().

func Open(cfg Config) (*DB, error)function

Initializes a DB handle with one master + N replicas. Pings all connections before returning. Returns error if master DSN is unreachable.

func (db *DB) Close() errormethod

Closes all database connections (master and replicas).

func (db *DB) Ping(ctx context.Context) errormethod

Verifies connectivity to master and all replicas.

func (db *DB) Dialect() Dialectmethod

Returns the SQL dialect for this connection.

func (db *DB) Master() *sql.DBmethod

Returns the underlying master *sql.DB for advanced use.

func (db *DB) Table(name string) *Buildermethod

Starts a fluent query builder for the given table name.

func (db *DB) Raw(sql string, bindings ...interface{}) *RawQuerymethod

Starts a raw SQL query that will execute against the DB.

func (db *DB) Model() *ModelDBmethod

Returns a ModelDB scoped to this connection for active-record operations.

func (db *DB) Begin(ctx context.Context, opts *sql.TxOptions) (*Tx, error)method

Starts a transaction on master. Always uses master for consistency.

func (db *DB) Transaction(ctx context.Context, fn func(tx *Tx) error) errormethod

Executes fn within a transaction. Auto-rollback on error, auto-commit on success. Panic-safe.

func (db *DB) TransactionWithOptions(ctx context.Context, opts *sql.TxOptions, fn func(tx *Tx) error) errormethod

Like Transaction but with custom sql.TxOptions.

func (db *DB) ScopeRegistry() *ScopeRegistrymethod

Returns the global scope registry for this DB connection.

func (db *DB) SetEventDispatcher(ed *EventDispatcher)method

Sets the event dispatcher for this DB connection.

func (db *DB) EventDispatcher() *EventDispatchermethod

Returns the event dispatcher for this connection.

func (db *DB) ExecContext(ctx context.Context, query string, args ...interface{}) (sql.Result, error)method

Executes a mutation (INSERT/UPDATE/DELETE) on master.

func (db *DB) QueryContext(ctx context.Context, query string, args ...interface{}) (*sql.Rows, error)method

Executes a SELECT on a replica (or master if sticky/FOR UPDATE).

func (db *DB) QueryRowContext(ctx context.Context, query string, args ...interface{}) *queryRowmethod

Executes a single-row SELECT on a replica.

ModelDB

Active-record-style model API. Created via DB.Model() or Tx.Model().

func (m *ModelDB) Create(ctx context.Context, model interface{}) errormethod

Inserts model, populates ID and timestamps. Fires Saving → Creating events, runs BeforeSave → BeforeCreate hooks, executes INSERT, runs AfterCreate → AfterSave hooks, then fires Created → Saved events.

func (m *ModelDB) Save(ctx context.Context, model interface{}) errormethod

Creates if PK is zero, otherwise updates. Fires full event lifecycle.

func (m *ModelDB) Update(ctx context.Context, model interface{}, changedCols ...string) errormethod

Updates model. If changedCols are specified, only those columns are updated. Requires PK to be set.

func (m *ModelDB) Find(ctx context.Context, model interface{}, id interface{}) errormethod

Retrieves record by PK. Applies global scopes, soft-delete filtering, and eager loading.

func (m *ModelDB) First(ctx context.Context, model interface{}, fn ...func(*Builder)) errormethod

Retrieves first matching record. Applies scopes, soft-delete, eager loading.

func (m *ModelDB) All(ctx context.Context, dest interface{}, fn ...func(*Builder)) errormethod

Retrieves all records into *[]T. Applies scopes, soft-delete, eager loading.

func (m *ModelDB) Where(ctx context.Context, dest interface{}, fn func(*Builder)) errormethod

Shorthand for All(ctx, dest, fn).

func (m *ModelDB) Delete(ctx context.Context, model interface{}) errormethod

Soft-deletes if model has deleted_at, otherwise hard-deletes. Fires Deleting → Deleted events.

func (m *ModelDB) ForceDelete(ctx context.Context, model interface{}) errormethod

Permanently deletes even if model uses soft deletes.

func (m *ModelDB) Restore(ctx context.Context, model interface{}) errormethod

Restores a soft-deleted record by setting deleted_at = NULL.

func (m *ModelDB) Paginate(ctx context.Context, dest interface{}, page, perPage int, fn ...func(*Builder)) (*Paginator, error)method

Paginated model query with scopes, soft-delete, and eager loading.

func (m *ModelDB) With(relations ...string) *ModelDBmethod

Prepares eager loading for named relationships. Supports dot notation for nested: "Posts.Tags".

Dialect (Interface)

Abstracts database-specific SQL generation.

Dialect { Name, QuoteIdentifier, Placeholder, SupportsReturning, UpsertClause }interface
Name() string
Dialect identifier: "postgres", "mysql", "sqlite3".
QuoteIdentifier(name string) string
Wraps identifier in dialect-specific quotes (", `).
Placeholder(index int) string
Returns bind placeholder: $N for Postgres, ? for MySQL/SQLite.
SupportsReturning() bool
True for Postgres and SQLite 3.35+.
UpsertClause(conflictCols, updateCols []string) (string, error)
Returns dialect-specific UPSERT suffix.
func GetDialect(driver string) (Dialect, error)function

Factory: returns PostgresDialect, MySQLDialect, or SQLiteDialect by driver name.

Built-in Implementations

PostgresDialectstruct

Quoting: "identifier". Placeholders: $1, $2, ... Supports RETURNING. UPSERT: ON CONFLICT (col) DO UPDATE SET col = EXCLUDED.col.

MySQLDialectstruct

Quoting: `identifier`. Placeholders: ?. No RETURNING. UPSERT: ON DUPLICATE KEY UPDATE col = new.col.

SQLiteDialectstruct

Quoting: "identifier". Placeholders: ?. Supports RETURNING (3.35+). UPSERT: ON CONFLICT DO NOTHING or ... DO UPDATE SET col = excluded.col.

Provides no-op defaults for all Observer methods. Embed to avoid implementing every method.
