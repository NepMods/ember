Changelog

All notable changes to ember are documented here. This project adheres to Semantic Versioning and follows the Keep a Changelog format.

v2.0.0
2026-03-15
Added
Eager loading — Full With() implementation supporting HasMany, HasOne, BelongsTo, BelongsToMany with dot-notation nesting.
Added
Migration DSL — Cross-dialect schema builder with Blueprint: ID, String, Integer, Text, JSON, Enum, Decimal, Timestamps, SoftDeletes, Foreign keys, Indexes.
Added
Master/Replica routing — Configurable master + N read replicas with round-robin load balancing and sticky reads.
Added
Event system — Observer-pattern dispatcher with 10 lifecycle events (Creating/Created, Updating/Updated, Saving/Saved, Deleting/Deleted, Restoring/Restored).
Added
Global scopes — Registry-based scope system with built-in ActiveScope, SoftDeleteScope, WithTrashedScope, OnlyTrashedScope.
Added
Attribute casting — Tag-based cast:json, cast:date, cast:datetime, cast:string, cast:int, cast:float, cast:bool.
Added
Builder macros — Per-instance and global extension mechanism for the query builder.
Added
Serialization package — ModelToMap, ToJSON, CollectionToMap, CollectionToJSON with configurable date formats.
Added
Connection Manager — Named connection registry supporting multiple database groups with thread-safe Add/Remove/CloseAll.
Added
Pagination — Separate COUNT + SELECT approach with metadata (CurrentPage, LastPage, PerPage, Total, From, To).
Changed
LoadBelongsTo now respects OwnerKey — v1 ignored the OwnerKey parameter; v2 resolves it from the relation definition.
Changed
Default() is type-aware — auto-quotes strings, maps bools to 1/0, handles nil as NULL.
Fixed
SQLite TEXT(N) generation — now maps all text-like types to plain TEXT instead of invalid TEXT(255).
Removed
Dead Builder.bindings field removed.
v1.0.0
2025-06-01
Added
Fluent query builder with full SELECT/INSERT/UPDATE/DELETE/UPSERT support.
Added
Active-record ModelDB with Create/Find/Save/Update/Delete.
Added
Dialect interface with PostgreSQL, MySQL, and SQLite3 implementations.
Added
Struct tag parsing (ember:"column:...;primaryKey;autoIncr").
Added
Transaction support with Commit/Rollback.
v0.1.0

Initial preview release. Core query builder with basic CRUD operations.

SQLite3 driver support with in-memory testing capability.
Added
Basic model definition through Go structs.
