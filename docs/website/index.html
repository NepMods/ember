ember

A full-featured, Laravel Eloquent-inspired ORM and query builder for Go.

v2.0.0 Go 1.26+ PostgreSQL MySQL SQLite3 ~3k LOC
Get Started API Reference Examples Architecture vs GORM/Bun/Ent

Features

Fluent Query Builder

Chainable SELECT/INSERT/UPDATE/DELETE/UPSERT builder with WHERE, JOIN, GROUP BY, HAVING, ORDER BY, LIMIT/OFFSET, aggregates, chunking, and lock modes.

Active-Record Models

Model layer with Create/Find/Save/Update/Delete/Restore/ForceDelete, automatic timestamps, soft deletes, lifecycle hooks, and eager loading.

Migration DSL

Cross-dialect schema builder with Blueprint: ID, String, Integer, Text, JSON, Enum, Decimal, Timestamps, SoftDeletes, Foreign keys, Indexes. Supports Up/Down/Rollback/Fresh.

Master/Replica Routing

Configurable master + N read replicas with round-robin load balancing. Sticky reads via context. All writes go to master; SELECTs balance across replicas.

Eager Loading

N+1 prevention via IN (...) queries. Supports HasMany, HasOne, BelongsTo, BelongsToMany with nested relations. Declarative tag-based definition.

Attribute Casting

Tag-based casting: cast:json, cast:date, cast:datetime, cast:string, cast:int, cast:float, cast:bool. Applied automatically on read/write.

Event System

Observer-pattern event dispatcher with 10 lifecycle events (Creating/Created, Updating/Updated, Saving/Saved, Deleting/Deleted, Restoring/Restored). Per-model and global observers.

Global Scopes

Registry-based scope system. Apply reusable query constraints per model type. Built-in scopes: ActiveScope, SoftDeleteScope, WithTrashedScope, OnlyTrashedScope.

Pagination

Separate COUNT + SELECT approach. Builder.Paginate and ModelDB.Paginate with metadata (CurrentPage, LastPage, PerPage, Total, From, To).

Raw SQL

Execute raw queries with Scan, First, Get, Exec, Pluck, Value. Full binding support. Transaction-aware.

Builder Macros

Extend the builder with custom methods. Per-instance via Macro() and global via AddBuilderMacro(). Dispatch with Call().

Serialization

ModelToMap, ToJSON, CollectionToMap, CollectionToJSON. Configurable date/datetime format. Timestamp and soft-delete filtering.

Connection Manager

Named connection registry for multiple database groups. Thread-safe Add/Remove/CloseAll. Switch between 'default', 'reporting', 'archive' etc.

Transaction Support

Begin/Commit/Rollback with savepoints. Transaction helper with auto-rollback on error. Builder and Raw methods fully work inside transactions.

Dialect Abstraction

Interface-based dialect system. PostgreSQL, MySQL, SQLite3 built-in. Custom dialects via interface implementation. Proper quoting, placeholders, RETURNING, UPSERT.

Quick Start

import ember "github.com/NepMods/ember"

// Open connection
db, err := ember.Open(ember.Config{
    Driver: "sqlite3",
    Master: ":memory:",
})
defer db.Close()

// Define model
type User struct {
    ID        int64      `ember:"primaryKey;autoIncr"`
    Name      string
    Email     string     `ember:"unique"`
    CreatedAt time.Time
    UpdatedAt time.Time
}

// Create
u := &User{Name: "Alice", Email: "alice@example.com"}
db.Model().Create(ctx, u)

// Find
var user User
db.Model().Find(ctx, &user, 1)

// Query
var users []User
db.Table("users").Where("email", "LIKE", "%@example.com").Get(ctx, &users)

// Paginate
paginator, _ := db.Table("users").Paginate(ctx, &users, 1, 15)

// Migrate
type CreateUsersTable struct{}
func (m *CreateUsersTable) Version() string { return "2024_01_01_create_users" }
func (m *CreateUsersTable) Up(s *ember.Schema) error {
    return s.Create("users", func(t *ember.Blueprint) {
        t.ID()
        t.String("name")
        t.String("email").Unique()
        t.Timestamps()
    })
}
func (m *CreateUsersTable) Down(s *ember.Schema) error {
    return s.Drop("users")
}
migrator := ember.NewMigrator(db, &CreateUsersTable{})
migrator.Run(ctx)
