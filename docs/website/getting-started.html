Installation

go get github.com/NepMods/ember

Then import it as a single flat package:

import ember "github.com/NepMods/ember"

No sub-packages, no complex import chains. One import, everything you need.

Configuration

Use Config to define a database connection group with one master and N read replicas:

db, err := ember.Open(ember.Config{
    Driver:   "postgres",
    Master:   "postgres://user:pass@localhost/mydb?sslmode=disable",
    Replicas: []string{
        "postgres://user:pass@replica1/mydb?sslmode=disable",
    },
    Pool: ember.PoolConfig{
        MaxOpenConns:    25,
        MaxIdleConns:    10,
        ConnMaxLifetime: 5 * time.Minute,
    },
})

Supported drivers: postgres (or pgx), mysql, sqlite3 (or sqlite).

If no replicas are provided, reads go to master. Use ember.WithStickyMaster(ctx) after writes to force reads to master.

For SQLite in-memory testing:

db, _ := ember.Open(ember.Config{
    Driver: "sqlite3",
    Master: ":memory:",
})

Define Your First Model

Models are plain Go structs with ember struct tags:

type User struct {
    ID        int64      `ember:"primaryKey;autoIncr"`
    Name      string
    Email     string     `ember:"unique"`
    Age       int        `ember:"default:0"`
    Status    string     `ember:` + "`" + `default:"active"` + "`" + ``
    Metadata  map[string]interface{} `ember:"cast:json"`
    CreatedAt time.Time
    UpdatedAt time.Time
    DeletedAt *time.Time `ember:"nullable"`
}

The table name is automatically derived from the struct name using snake_case pluralization (User → users). Override with the Tabler interface:

func (u *User) TableName() string { return "my_users" }

Tag Reference

TagDescription
column:nameOverride column name
primaryKeyMark as primary key
autoIncrAuto-incrementing
nullableAllow NULL
uniqueUnique constraint
default:valDefault value
cast:json|date|datetime|string|int|float|boolAttribute casting
-Skip field

Auto-Detected Columns

Column NameFeature
idAuto-detected as primary key (if no explicit primaryKey)
created_atAuto-set on create, cast as datetime
updated_atAuto-set on create/update, cast as datetime
deleted_atEnables soft deletes, cast as datetime

CRUD Operations

Create

user := &User{Name: "Alice", Email: "alice@example.com"}
err := db.Model().Create(ctx, user)
// user.ID and timestamps are populated automatically

Find by Primary Key

var user User
err := db.Model().Find(ctx, &user, 42)

// Or with a non-standard PK column
type CustomModel struct {
    UUID string `ember:"primaryKey"`
}
var m CustomModel
db.Model().Find(ctx, &m, "abc-123")

First / All with constraints

var user User
err := db.Model().First(ctx, &user, func(b *ember.Builder) {
    b.Where("email", "=", "alice@example.com")
})

var users []User
err := db.Model().All(ctx, &users)

var adults []User
db.Model().All(ctx, &adults, func(b *ember.Builder) {
    b.Where("age", ">=", 18).OrderBy("name", "ASC")
})

Where (shorthand)

var users []User
db.Model().Where(ctx, &users, func(b *ember.Builder) {
    b.Where("age", ">", 18).Where("status", "=", "active")
})

Update

user.Name = "Alice Smith"
user.Age = 31
err := db.Model().Save(ctx, &user)

// Update specific columns only
err := db.Model().Update(ctx, &user, "name", "email")

Delete (Hard & Soft)

// Hard delete (no deleted_at column)
err := db.Model().Delete(ctx, &user)

// Soft delete (sets deleted_at = now)
err := db.Model().Delete(ctx, &softDeletableUser)

// Force delete even with soft deletes
err := db.Model().ForceDelete(ctx, &user)

// Restore a soft-deleted record
err := db.Model().Restore(ctx, &user)

Migrations

Migrations implement the Migration interface:

type CreateUsersTable struct{}

func (m *CreateUsersTable) Version() string {
    return "2024_01_01_create_users"
}

func (m *CreateUsersTable) Up(s *ember.Schema) error {
    return s.Create("users", func(t *ember.Blueprint) {
        t.ID()
        t.String("name")
        t.String("email").Unique()
        t.String("status").Default("active")
        t.Timestamps()
        t.SoftDeletes()
    })
}

func (m *CreateUsersTable) Down(s *ember.Schema) error {
    return s.Drop("users")
}

Running Migrations

migrator := ember.NewMigrator(db, &CreateUsersTable{}, &CreatePostsTable{})
migrator.Run(ctx)                     // Run pending
migrator.Rollback(ctx, 1)            // Rollback last step
migrator.Rollback(ctx, 0)            // Rollback all
migrator.Fresh(ctx)                  // Drop all + re-run
statuses, _ := migrator.Status(ctx)  // List all with status

Blueprint Column Types

t.ID()                    // Auto-increment bigint PK
t.UUID()                  // UUID primary key (varchar 36)
t.String("name", 100)     // VARCHAR (default 255)
t.Text("body")            // TEXT
t.Integer("count")        // INT
t.BigInteger("views")     // BIGINT
t.SmallInteger("rating")  // SMALLINT
t.TinyInteger("flag")     // TINYINT
t.Float("score")          // FLOAT
t.Double("price")         // DOUBLE
t.Decimal("amount", 10, 2) // DECIMAL(10,2)
t.Boolean("active")       // BOOLEAN
t.Date("birthday")        // DATE
t.DateTime("published")   // DATETIME
t.Timestamp("created_at") // TIMESTAMP
t.JSON("metadata")        // JSON
t.JSONB("data")           // JSONB (Postgres)
t.Enum("status", []string{"draft","published"})
t.Binary("avatar")        // BLOB/BYTEA
t.Timestamps()            // created_at + updated_at
t.SoftDeletes()           // deleted_at

Foreign Keys & Indexes

s.Create("posts", func(t *ember.Blueprint) {
    t.ID()
    t.String("title")
    t.Text("body")
    t.UnsignedBigInteger("user_id")
    t.Timestamps()

    // Foreign key
    t.Foreign("user_id").References("id").On("users").CascadeOnDelete()

    // Indexes
    t.Index("title")
    t.UniqueIndex("slug")
})

Altering Tables

s.Table("users", func(t *ember.Blueprint) {
    t.String("phone").Nullable().After("email")
    t.DropColumn("legacy_field")
    t.Index("phone")
})

Relationships

Relationships are declared with ember:"relation:..." tags:

type User struct {
    ID        int64    `ember:"primaryKey;autoIncr"`
    Name      string
    Posts     []Post  `ember:"relation:hasMany;foreignKey:user_id;localKey:id"`
    Profile   Profile `ember:"relation:hasOne;foreignKey:user_id;localKey:id"`
}

type Post struct {
    ID      int64  `ember:"primaryKey;autoIncr"`
    UserID  int64  `ember:"column:user_id"`
    Title   string
    Author  User   `ember:"relation:belongsTo;foreignKey:user_id;ownerKey:id"`
    Tags    []Tag  `ember:"relation:belongsToMany;pivot:post_tags;pivotFK:post_id;pivotRK:tag_id"`
}

type Tag struct {
    ID   int64  `ember:"primaryKey;autoIncr"`
    Name string
}

Relation Tag Reference

KeyDescription
relation:hasManyOne-to-many relationship
relation:hasOneOne-to-one relationship
relation:belongsToInverse one-to-one/many
relation:belongsToManyMany-to-many via pivot
foreignKeyForeign key column on related table
localKeyLocal key column on parent table
ownerKeyKey on parent table (BelongsTo)
pivotPivot table name (BelongsToMany)
pivotFKPivot foreign key column
pivotRKPivot related key column

Loading Single Relations

var user User
db.Model().Find(ctx, &user, 1)

var posts []Post
db.Model().LoadHasMany(ctx, &user, ember.HasMany{ForeignKey: "user_id"}, &posts)

var profile Profile
db.Model().LoadHasOne(ctx, &user, ember.HasOne{ForeignKey: "user_id"}, &profile)

var author User
db.Model().LoadBelongsTo(ctx, &post, ember.BelongsTo{ForeignKey: "user_id"}, &author)

var tags []Tag
db.Model().LoadBelongsToMany(ctx, &post, ember.BelongsToMany{
    PivotTable: "post_tags", ForeignKey: "post_id", RelatedKey: "tag_id",
}, &tags)

Eager Loading

Use With() to eager-load relationships and eliminate N+1 queries:

var users []User
db.Model().With("Posts", "Profile").All(ctx, &users)

// Nested eager loading
db.Model().With("Posts.Tags").All(ctx, &users)

// With constraints
var user User
db.Model().With("Posts").Find(ctx, &user, 1)

Eager loading executes two queries instead of one complex JOIN, using WHERE fk IN (...) to collect related records, then groups them in memory by foreign key.

Scopes

Scopes are reusable query constraints:

// Define a scope
func ActiveScope(b *ember.Builder) *ember.Builder {
    return b.Where("status", "=", "active")
}

// Apply to a query
ember.ApplyScopes(db.Table("users"), ActiveScope).Get(ctx, &users)

// Built-in scopes
db.Model().All(ctx, &users) // automatically applies registered global scopes

Global Scopes

Register scopes that apply automatically to all queries for a model type:

db.ScopeRegistry().Add(&User{}, ActiveScope)

// Now every User query includes status = 'active'
db.Model().All(ctx, &users)
db.Model().Find(ctx, &user, 1)

// Built-in helpers
ember.ActiveScope(b)      // WHERE status = 'active'
ember.SoftDeleteScope(b)  // WHERE deleted_at IS NULL
ember.WithTrashedScope()  // Remove soft-delete filter
ember.OnlyTrashedScope()  // Only deleted records

Events

ember supports 10 lifecycle events via the Observer pattern:

// Using the Observer interface
type AuditObserver struct {
    ember.BaseObserver
}
func (o *AuditObserver) Created(ctx context.Context, model interface{}) error {
    log.Printf("Created: %T %+v", model, model)
    return nil
}

// Using ObserverFuncs
obs := &ember.ObserverFuncs{
    SavedFunc: func(ctx context.Context, m interface{}) error {
        log.Printf("Saved: %+v", m)
        return nil
    },
}

// Register per-model
dispatcher := ember.NewEventDispatcher()
dispatcher.Observe(&User{}, &AuditObserver{})
dispatcher.Observe(&User{}, obs)
db.SetEventDispatcher(dispatcher)

// Register global observer (all models)
dispatcher.ObserveAll(&AuditObserver{})

Hook Interfaces

Models can also implement hook interfaces directly:

type User struct { ... }
func (u *User) BeforeCreate(ctx context.Context) error {
    if u.Name == "" { return fmt.Errorf("name required") }
    return nil
}

Available hook interfaces: BeforeCreator, AfterCreator, BeforeSaver, AfterSaver, BeforeUpdater, AfterUpdater, BeforeDeleter, AfterDeleter.

Event Lifecycle Order

Create:    Saving → Creating → BeforeSave → BeforeCreate → [SQL INSERT] → AfterCreate → AfterSave → Created → Saved
Update:    Saving → Updating → BeforeSave → BeforeUpdate → [SQL UPDATE] → AfterUpdate → AfterSave → Updated → Saved
Delete:    Deleting → BeforeDelete → [SQL DELETE] → AfterDelete → Deleted
Restore:   Saving → Restoring → BeforeSave → [SQL UPDATE] → AfterSave → Restored → Saved

Serialization

// Map
m, _ := ember.ModelToMap(user)
// {"id":1, "name":"Alice", "created_at":"2024-01-15T10:00:00Z"}

// JSON
json, _ := ember.ToJSON(user)

// Collections
list, _ := ember.CollectionToMap(users)
json, _ := ember.CollectionToJSON(users)

// With config
cfg := &ember.SerializationConfig{
    DateFormat:        "2006-01-02",
    DateTimeFormat:    "2006-01-02 15:04:05",
    IncludeTimestamps: false,
    IncludeSoftDelete: false,
}
m, _ := ember.ModelToMapWithConfig(user, cfg)
